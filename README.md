# AI Job Description Analyzer

## Overview

A full-stack web application built with React, Node.js, Express, and PostgreSQL that analyzes job descriptions using the OpenAI API. The application helps users evaluate job opportunities by generating AI-powered recommendations and storing previous analyses for future reference.

## Features

- AI-powered job analysis using the OpenAI API
- React frontend with Express backend
- RESTful API communication
- PostgreSQL database for storing job analyses
- Docker containerization
- GitHub Actions continuous integration

## Technologies

- React
- Node.js
- Express
- PostgreSQL
- OpenAI API
- Docker
- GitHub Actions

## Running the Project

### Live Demo

```bash
git clone https://github.com/Egaytan23/ai-job-agent.git
```
