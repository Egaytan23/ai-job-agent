# AI Job Description Analyzer

## Overview

A full-stack web application that analyzes job descriptions using the OpenAI API and stores previous analyses in PostgreSQL.

## Features

- AI-powered job analysis
- REST API
- PostgreSQL database
- React frontend
- Docker support
- GitHub Actions CI

## Technologies

- React
- Node.js
- Express
- PostgreSQL
- OpenAI API
- Docker
- GitHub Actions
